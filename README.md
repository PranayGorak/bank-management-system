

# Bank Management System

A console-based Bank Management System developed using Java to demonstrate the practical implementation of core Object-Oriented Programming concepts. The application allows users to create and manage bank accounts while performing essential banking operations such as deposits, withdrawals, balance inquiries, account information management, and fund transfers.

## Features

* Create Savings and Current Accounts
* Deposit and withdraw money
* Check account balance
* View account details
* Transfer money between accounts
* Automatic account number generation
* Interactive console-based menu

## OOP Concepts Used

* Classes and Objects
* Constructors
* Constructor Overloading
* Method Overloading
* Method Overriding
* Inheritance
* Encapsulation
* Abstraction
* Interfaces
* Access Modifiers
* Static Keyword
* Packages

## Technologies Used

* Java
* Object-Oriented Programming
